## 📖 About the Project

**Amit Chavda's React Portfolio** is a personal portfolio website created to present my web development skills, projects, and technical learning journey.

The main goal of this project is to build a professional online presence where recruiters, developers, and potential collaborators can learn about my skills and explore my work.

Through this project, I am improving my knowledge of React.js, component-based development, responsive user interfaces, and modern frontend development practices.

## 🎯 Project Objectives

- Build a professional developer portfolio.
- Showcase personal and academic projects.
- Demonstrate frontend development skills.
- Practice React components and reusable UI structures.
- Create an accessible way for recruiters to explore my work.
- Continue improving my skills through practical development.

## ⚙️ Getting Started

Follow the steps below to download and run the project on your local machine.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

Check your installed versions:

```bash
node -v
npm -v
git --version
```

### Step 1: Clone the Repository

```bash
git clone https://github.com/chavdaamit/React-portfolio.git
```

### Step 2: Navigate to the Project Directory

```bash
cd React-portfolio
```

### Step 3: Install Dependencies

```bash
npm install
```

### Step 4: Start the Development Server

If the project uses Vite:

```bash
npm run dev
```

If it uses another build tool, use the development command defined in `package.json`.

### Step 5: Open the Website

Open the local URL displayed in your terminal. For a typical Vite setup, it is:

```text
http://localhost:5173
```
